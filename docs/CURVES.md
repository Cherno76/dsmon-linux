# 活动曲线与流量曲线

两张图都来自源项目的侧边刘海（`SideNotchView` / `ActivityCurveRenderer` /
`TrafficCurveRenderer`），在 TUI 里是“概览”页的实时面板。参数必须保持一致，否则数字和图会对不上。

## 1. 活动曲线

回答：“最近两分钟，请求什么时候来过、密不密。”

| 项 | 值 |
|---|---|
| 桶宽 | 6 秒 |
| 桶数 | 20（窗口 120 秒） |
| 每桶含义 | 该 6 秒内**请求发出**的次数 |
| 满量程 | 3 次/桶（`curveFullScale = 3`） |
| 网格 | 无（只画曲线填充） |
| 打点时机 | 请求**发出**那一刻；完成不重复记 |
| 颜色 | 健康 = 绿；异常 = 红 |

规则（源 `ActivityTrace.swift`）：

- 桶号按**绝对时间**对齐：`floor(unixSeconds / 6)`，不是从启动算起。
- 读取路径也要 `advance(to: now)`，跨过的桶补 0；否则空闲时图会冻住。
- 时钟回拨忽略：时间只往前走。
- 静了超过整个窗口：全部清零，最后一格对准当前。

异常判定（源 `ActivityMeter.idleHealth`，去掉余额告警部分）：

- 代理没在跑 / listener 报错；
- 最近一次上游响应 ≥ 500；
- 余额查询失败（可选，默认只影响文字颜色，不影响曲线）。

## 2. 流量曲线

回答：“刚刚上下行有多快。”

| 项 | 值 |
|---|---|
| 桶宽 | 0.5 秒 |
| 桶数 | 3600（保留 30 分钟，显示窗口由画布宽度决定） |
| 每桶 | `upload` 与 `download` 两个字节数 |
| 口径 | 只算 HTTP **正文**，不含头 |
| upload | 实际发给上游的那一份（大图 offload 之后，不是客户端原样） |
| download | 转发给客户端的每个分片 |
| 泳道 | 下载在上半、上传在下半，共用中线和盲文画布 |
| 量程 | 两条半区**各算各的** |
| 最低量程 | 1024 B/s |
| 网格 | 无竖网格；中线是一条公共盲文基线 |

### 量程

- 峰值：当前画布可见窗口里最忙的 0.5 秒桶，换算成 B/s。
- 量程 = `peak × 1.25` 后就近取整，夹住 1KB/s 下限；取整步长（B/s）：
  `<10K` 用 500，`10K–100K` 用 10K，`100K–1M` 用 50K，`1M–10M` 用 500K，
  `10M–100M` 用 5M，`≥100M` 用 50M。低于 10K 的 0.5K 粒度是为了避免
  1.5K 被取整成 0 或 10K。
- 量程标签使用十进制 1000 进制：30K、100K、150K、1.0M；不再用 1024 进制把
  实际 100K 显示成 98K、实际 150K 显示成 146K。
- 棘轮：涨档**即时**；峰值低于当前量程 25%、连续安静 20 秒后，才**降一档**。
- 降档取当前量程以下最近的取整档位，例如 150K → 100K、400K → 350K。
- 上下行量程接近时合并：`max(down, up) / min(down, up) < 2` 就统一到较大值，
  例如 60K/70K → 70K/70K；正好 2 倍（50K/100K）或更远则保持各自量程。
- 默认线性轴；对数轴代码路径保留但默认关闭（`usesLogarithmicScale = false`）。

### 速率读数

- 取最近 2 秒（默认 4 个 0.5 秒桶）里的**最大值**（不是平均），除以各桶时长。
- 显示迟滞：一次变化后 2 秒内不再改；相对变化 < 25% 不改。
- 低于 10 B/s 直接显示 0；从 0 起跳、落回 0 都即时。
- 单位：Byte/s、KiB/s、MiB/s（1024 进制）；括号内同时显示 bit 速率，例如
  `1.29 KiB/s (10.3 Kibps)`。

### btop 统计框

- 右侧统计框复刻 btop `Net::draw`：宽 27 列，窄屏退到 19 列；高度最多 9 行，在面板内垂直居中。
- 统计框边框使用 btop 当前主题的 `div_line` 灰色 `#414868`，标题仍用 `title` 色；
  终端无法改变字符线宽，灰色让子框边框在视觉上后退，接近 btop 的细灰线。
- 同一个框的上边框嵌 `download`、下边框嵌 `upload`；下载三项贴着上边框，上传三项贴着下边框，
  中间留一行空白。宽度不足 20 时隐藏 bit 速率。
- 每侧依次显示：`▼/▲ 速率 (bit 速率)`、`▼/▲ Top: (bit 速率)`、`▼/▲ Total: 字节总量`。
- `Top` 和 `Total` 是进程内累计值：`Top` 记录出现过的最高 0.5 秒桶速率，`Total` 记录自
  daemon 启动以来累计转发的正文字节；重启后归零。
- 单位算法直接照 btop `floating_humanizer`：二进制后缀 `Byte/KiB/MiB/GiB`，bit 后缀
  `bit/Kib/Mib/Gib`，并保留其整数移位后再插小数点的截断行为（例如 1331 B/s 的 bit 速率
  显示 `10.3 Kibps`，不是数学四舍五入的 `10.4`）。

## 3. TUI 画法

### 布局

```
╭─┐账户 ┌──────────────────────────╮ ╭─┐活动 · 2 分钟 · 3 req/格 ┌────╮
│ 余额 ...                                                 │ │ ⣀⣠⣤⣶⣿⣷⣶⣤⣄ │
╰──────────────────────────────────────────────────────────╯ ╰─────────────────╯
╭─┐流量 · 170 秒 · 自动量程 ┌─────────────────────────────────────────────╮
│ 1.0K ⣀⣤⣶⣿⣷⣶⣤⣄  ╭┐download┌─╮                              │
│      ⣀⣴⣾⣿⣷⣦⡀  │▼ 1.3 KiB/s │                              │
│ ───────────────── │▼ Top:     │                              │
│      ⣀⣴⣾⣿⣷⣦⡀  ╰┘upload└─╯                              │
╰────────────────────────────────────────────────────────────────────────────╯
```

- 概览首行把账户与活动并排：账户占左侧 `width - 1 - width/3` 列，活动占右侧 `width/3`
  列，中间留 1 列；活动与账户同高。流量独占下一整行，能显示更多时间点和完整统计框。
- 终端内容宽度 <60 列时回退为账户整行、活动和流量上下堆叠，避免活动面板窄到放不下标题。
- 边框：采用 btop `createBox` 的圆角嵌入式标题，标题只占上边框，不额外占行；活动、流量、
  账户、请求分别使用紫、粉、绿、蓝边框色。
- 画布：Unicode Braille（U+2800 起），每字符 2 列 × 4 行点。流量每个点列对应一个
  0.5 秒桶，即每个盲文字符承载两个相邻样本，与 btop 的 net deque 密度一致。
- 可见时间窗按画布宽度决定，不再固定 120 秒：每个点列对应一个 0.5 秒桶，每个字符两列，
  所以图宽每增加一个字符，就多显示约 1 秒历史。daemon 保留最近 3600 个桶（30 分钟），
  IPC 按请求宽度只发送最近 `width*2` 个桶，宽屏会自然铺满并显示更长的历史。
- 最右侧永远是最新桶，历史桶按 0.5 秒节奏向左移动；每个桶固定占一个点列，不拉伸也不
  插值，避免同一个桶在 1/2 个点列之间变化。若传入的历史少于画布宽度，则右对齐留空。
- 流量面板整体照 btop Net：下载图在上半区、上传图在下半区，两半共用一块盲文画布，但各自
  有一条基线：下载以中线最后一行为零线向上填充，上传以中线后第一行为零线向下填充。
  每个点列从自己的基线填到对应桶的原始高度，形成整条面积和清晰的单桶竖线。
- 不做显示处理：上下行都直接使用 daemon 的 0.5 秒原始桶，不向相邻点列扩散尖峰，也不做
  线性插值；最新桶仍在最右侧，历史桶按采样节奏向左移动。

### 余额趋势

- 账户面板里的 24h/7d 趋势各占一行，分别使用独立的 min/max 量程。
- 横轴是时间，固定左旧右新；纵轴是余额，低值在下、高值在上。趋势行直接显示
  `余额  24h <min>–<max> ...  时间→`，避免把 min/max 误读成横轴方向。
- 宽度 ≥64 列时显示每条趋势的数值范围，≥56 列时显示 `时间→`；更窄时只保留系列名和点阵。
- 每个趋势行仍是一格 2×4 点的盲文画布：宽度 24 时横向有 48 个点列；从底部按当前值向上
  填充，因此高值出现更高的点列，低值至少保留底部一个点。
- 每个盲文格按该格最高的点列取值，做低→高渐变：低值 `#f7768e`（粉红），中值
  `#e0af68`（黄），高值 `#9ece6a`（绿）；标签本身保持正文色。
- 趋势只画数据点，不画网格；24h/7d 标签和数值文本不变。
- `--ascii` 或 `NO_COLOR=1` 时回退为 `▁▂▃▄▅▆▇█` 块字符，保证缺少盲文字体时仍可读。
- 点映射（x 右、y 下）：

```
dot1 0x01 (0,0)   dot4 0x08 (1,0)
dot2 0x02 (0,1)   dot5 0x10 (1,1)
dot3 0x04 (0,2)   dot6 0x20 (1,2)
dot7 0x40 (0,3)   dot8 0x80 (1,3)
```

- 活动曲线：填充面。对每个点列，用相邻四个桶做 Catmull-Rom 平滑插值得到高度，从底填到该高度；
  端点取原桶值，插值结果夹在 0 到满量程之间，避免尖角和越界。
- 流量曲线：下载拿 `(height+1)/2` 行、上传拿剩余行；下载从上半区底边向上填，上传从下半区
  顶边向下填，量程文字分别叠在左上角和左下角。
- 网格：活动曲线不画竖向时间参考线，避免与填充面混在一起；流量图同样不画竖向时间网格，
  只保留下载/上传各自的一条零线，和 btop Net 的两个独立 Graph 一致。
- 颜色：活动绿/红；流量渐变直接取当前 Omarchy btop 主题：下载 `#e0af68 → #f7768e → #f7768e`
  （黄到粉），上传 `#9ece6a → #449dab → #7aa2f7`（绿到青到蓝）；流量面板边框使用粉色，
  活动面板边框使用紫色。
- **不做呼吸动画**；异常只在标题旁显示红色 `●`。

### 尺寸与刷新

- 活动面板建议 6 行；流量面板建议 10 行以上，才能完整显示统计框的速率、Top 和 Total。
- 每秒重绘；x 位移 = 桶相位 × 每桶点数，量化到 1 个点列，视觉上连续左移。
- 终端宽度小于 43 个内容列时统计框退到 19 列并隐藏 bit 速率；再窄则只保留左侧镜像图。
- 终端宽度变化时按新宽度重算可见窗口：IPC 取最近 `width*2` 个桶，每个桶仍固定一个点列；
  daemon 的 3600 个桶保留量不变，标题里的秒数随可见画布宽度变化。

### 回退

- 终端字体没有 Braille：活动改用 `▁▂▃▄▅▆▇█` 柱状图；流量改用上下两条 `sparkline`，
  两条道各自叠加箭头与速率。
- `NO_COLOR=1`：只用亮度区分，异常用 `!` 标记。

## 4. 用量页堆叠柱状图

- 横轴：时间桶，左旧右新。`今日`/`昨日` 等小时范围按小时分桶；跨天范围按天分桶。
- 纵轴：每个时间列的总 tokens，包含当前分组下所有模型或客户端的堆叠量；`0` 在底部，
  最大值在顶部，柱子从底边向上生长。
- 柱高按“渲染列”的合计值归一化，量程上限取所有渲染列中的最大值；当终端列数少于时间桶数时，
  一个渲染列会合并多个桶，轴上限也按合并后的合计值计算。
- 图表铺满面板可用宽度：桶数少于列数时重复采样相邻桶，不再把柱子挤在左侧；桶数多于列数时
  合并相邻桶。
- 坐标轴直接画在图内：左侧纵轴显示顶部最大值、中部约 50% 值和底部 `0`，纵轴字符在刻度行
  使用 `┤`；底部横轴使用 `└─┬→`，中间刻度与左旧右新的时间标签对齐。纵轴留白取三个刻度
  文本的最大宽度，例如 `1.6M` 与 `799.2K` 并存时两者共用同一个轴线列。
- 横轴标签按桶类型格式化：小时桶为 `15:04`，天桶为 `01/02`；左端是区间起点，右端是区间
  终点。小时区间恰在次日零点结束时显示 `24:00`；天区间恰在次日零点结束时显示最后一天
  （例如整月显示 `11/30`，不显示下月边界 `12/01`）。宽度不足时优先保留两端，再按空间
  显示中间刻度。
- 标题只保留 `用量趋势 · tokens · 今日 · 按模型`，不再依赖标题解释坐标方向；柱形字符和底部
  图例继续用于区分模型/客户端。
- 柱体使用盲文点阵作为填充纹理，单系列为 `⣿`，堆叠系列依次使用 `⠿⡿⢿⣷⣾⣻⢾`；底部图例
  使用同一组点阵标记。点阵只负责纹理和系列区分，不做曲线插值。
- 柱体按所在纵轴高度着色：底部 `0` 为绿 `#9ece6a`，约 50% 为黄 `#e0af68`，顶部为红
  `#f7768e`，中间做 RGB 线性插值。同一高度行的所有系列共用颜色，因此柱越高，红色段越靠上。
- `--ascii` 或 `NO_COLOR=1` 时坐标轴回退为 `+ | - >`，刻度标签语义不变。
- 该图是柱状图，只用盲文点阵作为柱体纹理，不做活动/流量曲线的点间插值。

## 5. 测试

- 纯逻辑：桶对齐、补零、时钟回拨、窗口滑出、量程档位、棘轮升降、速率迟滞，以及 2 秒
  速率窗口不随桶宽变化。
- 渲染：给定固定帧和固定宽度，断言字符矩阵（golden 字符串），不依赖终端；流量还要断言
  上下镜像半区、单条公共基线、居中统计框、`download/upload` 标题、Top/Total 和独立量程。
- 边界：全 0、只有最后一格有值、单格尖峰、宽度 40/80/200 列。

源测试参考：`ActivityTraceTests`、`TrafficTraceTests`、`ActivityCurveRendererTests`、
`TrafficCurveRendererTests`、`StatusBarAnimationTests`。
